# Changelog

All notable changes to Bullwheel are recorded here, grouped by version and generated from commit history.

## [0.0.6] - 2026-07-08

### Features

- Implemented Ascend, Bullwheel, and Warehouse Workspaces.
- Added Desktop icons for easy Workspace access.

### Bug Fixes

- Fixed Server Error resulting from missing parameter when retrieving Ascend record count.

- Added the "Print Label" button group to Ascend Product. (`a3462c8`)

- Permitted Warehouse Location Group status changes. (`e42549d`)
- Added Swap/Online price edit functionality. (`97ebe97`)
